Found it

Your regex expects the keys in Red, Green, Blue order, but WolvenKit 9.1 writes them alphabetically: Alpha, Blue, Green, Red. So the pattern never matches, and "zero hits" just means the scanner was blind.

Parse the JSON instead of matching text, so key order stops mattering:

pythonCopy
def walk(node, hits):
    # any dict with all four channels is a colour
    if isinstance(node, dict):
        if {"Red", "Green", "Blue"} <= node.keys():
            rgb = (node["Red"], node["Green"], node["Blue"])
            if rgb == (255, 6, 181):
                hits.append(node)
        for v in node.values():
            walk(v, hits)
